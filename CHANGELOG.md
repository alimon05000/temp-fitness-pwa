# Изменения

## 1.0.0 — 25 октября 2026

- Первое локальное приложение «ТЕМП» с четырьмя основными вкладками, календарём, профилем и ИИ-чатом.
- IndexedDB, цели, шаблоны, бег, подтягивания, произвольные занятия, пауза и отдых по меткам времени.
- Реальная аналитика, JSON/CSV, офлайн app shell и GitHub Pages workflow.
- Отдельный защищённый Tooken endpoint; не активирован без серверных секретов.
- Публикация ожидает авторизацию GitHub владельца `alimon05000`.
